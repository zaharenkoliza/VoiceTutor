## Инструкция по заполнению

1. Скопируйте блок «Сессия №___» для каждой новой сессии наблюдения
2. Заполняйте метаданные до начала сессии
3. Фиксируйте наблюдения в реальном времени или сразу после завершения
4. Для привязки к количественным данным используйте ID сессии из CSV-экспорта логгера
5. Старайтесь описывать наблюдаемое поведение, а не интерпретации

> **Примечание**: этот шаблон подготовлен в рамках НИР-2 для использования в будущих экспериментальных сессиях (НИР-3).
> Наблюдения пока не проводились — шаблон будет заполняться при проведении эксперимента.
