# Чек-лист пилота

## До сессии

- [ ] Заполнены `researcherContact` и `dataRetentionInfo` в consent config; текст одобрен ответственным исследователем.
- [ ] API работает по HTTPS; `ALLOWED_ORIGINS` содержит только фактические frontend origins.
- [ ] Заданы `LLM_PROVIDER`, `LLM_BASE_URL`, точный `LLM_MODEL`, серверный `LLM_API_KEY`, случайные session/researcher secrets.
- [ ] Выполнены `npm run build`, `npm run lint`, `npm --prefix server test`.
- [ ] Пройден полный браузерный тест каждой из четырёх схем с реальным микрофоном и живой LLM.
- [ ] Проверено, что просьбы о полном решении/ответе получают отказ; инциденты утечки всё равно предусмотрены для ручной разметки.
- [ ] Проверены PostgreSQL, права researcher export, резервная копия и пробное восстановление Managed PostgreSQL.
- [ ] Наборы A/B рассмотрены как кандидаты; результаты пилота не интерпретируются как доказательство равносложности.
- [ ] Используется уникальный анонимный код; тестовые коды имеют префикс `TEST` и исключаются из анализа.

## Во время сессии

- [ ] Участник прочитал согласие; ФИО/email не вводятся.
- [ ] System check подтвердил микрофон, Speech API, API и инициализацию Pyodide.
- [ ] Участник прошёл обе тренировочные задачи; они не входят в основные показатели.
- [ ] Исследователь не меняет режим внутри блока.
- [ ] При отказе микрофона нет скрытого перехода в text: повторить STT либо завершить попытку и записать причину.
- [ ] Запуск кода не трактуется как сдача ответа; технический сбой не помечается как неправильный ответ.
- [ ] При reload восстановить сессию; интервалы `performance.now()` по разные стороны reload не объединять.
- [ ] На завершении дождаться статуса `Синхронизировано`.

## После сессии

- [ ] Через researcher endpoint выгружены полный JSON и CSV (`sessions`, `task_attempts`, `events`, `questionnaire`).
- [ ] Проверены связи по participant/session/block/taskAttempt/request IDs и статусы завершения.
- [ ] Данные скопированы в резервное хранилище; тестовые записи отделены.
- [ ] Отмечены технические сбои, прерывания, пропуски и возможные утечки ответа тьютором.
- [ ] Не рассчитываются WER/CER без эталонной транскрипции, IRA/coverage без правил разметки и показатели усвоения без отдельной проверки знаний.
